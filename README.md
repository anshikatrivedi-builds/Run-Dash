
# 🏃 Jungle Dash — Temple Run Inspired Game

Jungle Dash is a browser-based endless runner game inspired by Temple Run. Run through an ancient jungle, dodge obstacles, jump over barriers, slide under arches, and collect golden coins while trying to achieve the highest score.

## 🎮 Features

- 🏃 Endless running gameplay
- 🪙 Collect coins and increase your score
- ⬅️➡️ Change lanes to avoid obstacles
- ⬆️ Jump over obstacles
- ⬇️ Slide under barriers
- 🌴 Jungle and ancient temple-inspired environment
- 📱 On-screen controls for mobile devices
- 🔄 Restart and play again
- ⚡ Built with HTML, CSS, and JavaScript
- 🌐 Runs directly in a web browser

## 🛠️ Technologies Used

- **HTML5** — Game structure
- **CSS3** — Styling and user interface
- **JavaScript** — Game logic, controls, collision detection, scoring, and animation
- **HTML Canvas** — Drawing the game environment, player, coins, and obstacles

## 🚀 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html`.

4. Run the file in your browser, or use the Live Server extension in VS Code.

5. Click **START RUN** and enjoy the game!

## 🕹️ Controls

| Key | Action |
|---|---|
| ← | Move left |
| → | Move right |
| ↑ | Jump |
| Space | Jump |
| ↓ | Slide |
| A / D | Change lanes |
| W / S | Jump / Slide |

You can also use the on-screen buttons.
